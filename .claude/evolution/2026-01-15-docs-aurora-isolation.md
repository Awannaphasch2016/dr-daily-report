## The Bug

### What Was Documented (WRONG)

Multiple files claimed Aurora is "shared" across environments:

**File: `.claude/commands/provision-env.md`**
```markdown
| Aurora MySQL | | ✓ (same cluster) |
...
**What is shared**: Aurora database, S3 buckets, ECR repository
...
**Aurora** | ~$43/month | $0 (shared)
```

**File: `.claude/commands/env.md`**
```markdown
- **Shared**: Aurora may be shared with dev (depends on provisioning)
```

### What Is Actually True (From Terraform)

**File: `terraform/aurora.tf` (line 206-207)**
```hcl
resource "aws_rds_cluster" "aurora" {
  cluster_identifier = "${var.project_name}-aurora-${var.environment}"
```

Aurora IS isolated per environment. Each `terraform apply` with a different `-var-file` creates a NEW Aurora cluster.

## Lessons Learned

### For Documentation
1. **Cross-reference with code**: Infrastructure claims must be verified against Terraform
2. **Separate recommendations from facts**: If suggesting cost optimization, say "recommended" not "is"
3. **Include cost implications**: Users need to know +$43/month per environment

### For Principle #2 (Progressive Evidence)
This is a meta-failure of Principle #2:
- Documentation was Layer 1 evidence (written claim)
- Terraform code is Layer 4 evidence (ground truth)
- Should have verified Layer 4 before documenting
